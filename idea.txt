- input: string
- output: PNG with qr-code

- restrictions:
    - string must be null terimanted (it should be done on our sied)
    - string should be parsed on our side to UTF-8 lowercase only
    - string should be validated against valid url
    - string must be shorter than 501 characters    

- output format should be:
    - png
    - jpg
    - svg

GenerateQr.h/.cpp – funkcja/klasa use-case.

src/infrastructure/

QrPngWriter.h/.cpp – zapis do PNG/SVG.

src/cli/

src/gui/ (później)
